# C12 — Ponte entre Linux e o kernel educacional

**Objetivo:** comparar contratos e limitações, não alegar compatibilidade binária.

`labs/low-level/C12/contracts.json` registra cinco áreas: syscalls, ELF, armazenamento, isolamento de falhas e procfs. `PARTIAL` significa apenas correspondência conceitual ou de mecanismo, **não** que um binário Linux rode no kernel B.

## Executar

```sh
make -C labs/low-level/C12 test
make -C labs/low-level/C08 test
make verify-kernel-docker
```

Os três comandos têm escopos distintos: o primeiro verifica a integridade da matriz, o segundo usa Linux real, o terceiro inicia o kernel B em QEMU. A matriz não é prova de equivalência entre os ambientes.

## Experimento de revisão

Escolha uma syscall Linux de C03/C08 e compare número, registradores, retorno e tratamento de erro com B08. Registre fonte do código, commit e uma divergência reproduzível. Faça o mesmo com `PT_INTERP` de C11 e B09.

## Controle negativo

Mude `elf.status` para `PASS` numa cópia temporária. O teste deve falhar, impedindo alegação indevida de compatibilidade.
