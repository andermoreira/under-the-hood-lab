# C07 — Flags, aritmética, bitwise e overflow

## Previsão

- Qual a diferença entre `CF` (carry) e `OF` (signed overflow)?
- O que acontece quando somamos 1 a `UINT64_MAX`? E a `INT64_MAX`?
- Por que capturar `CF`/`OF` imediatamente após `add`?
- Qual o resultado de `0xAA55 XOR 0xFFFF`?

## Execute

```sh
make -C labs/low-level/C07 test
make -C labs/low-level/C07 inspect
```

As funções Assembly calculam soma de 64 bits e expõem `CF` com `setc`, `OF` com `seto`, além de demonstrar `xor`. O código C compara os resultados com valores esperados nos limites. O wrap de `int64_t` é produzido no Assembly e interpretado na plataforma x86-64 de complemento de dois; **não** reproduza overflow assinado diretamente em C, pois isso seria comportamento indefinido.
