# C10 — Observabilidade real com /proc

Inspecione um processo vivo no Linux por `/proc/<pid>/status`, `stat` e `maps`. Os dados vêm do kernel Linux, não de uma simulação.

## Hipótese

Quais métricas são instantâneas? O que pode variar entre duas leituras? Por que RSS não é memória virtual total?

## Executar

```sh
make -C labs/low-level/C10 test
make -C labs/low-level/C10 inspect
```

O teste valida PID/PPID, threads e mapas de memória; também confirma que um PID inexistente falha explicitamente. Não atribua ao campo `state` estabilidade temporal. `/sys` será explorado em extensão posterior; este incremento cobre `/proc`.

## Controle negativo

Use um PID inexistente. A leitura deve levantar FileNotFoundError; não inventar métricas ou substituir por zero.

## Ponte com Trilha B

O kernel educacional B não implementa procfs. Este exercício ensina observabilidade do Linux real, não demonstra que B10 ou B12 oferecem as mesmas interfaces.
