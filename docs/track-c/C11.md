# C11 — Linkagem estática e dinâmica no Linux x86-64

## Hipótese (preencha antes de executar)

Qual binário terá segmento `INTERP`? Qual terá `DT_NEEDED`? Por quê? Compare o tamanho dos arquivos.

## Executar

```sh
make -C labs/low-level/C11 test
make -C labs/low-level/C11 inspect
file labs/low-level/C11/dynamic labs/low-level/C11/static
```

O exemplo compila **o mesmo programa C** com libc dinâmica e estática. O teste executa os dois, verifica saída exata, segmento `INTERP` e dependências `NEEDED`. A opção `-static` depende da libc estática instalada (por exemplo, `libc6-dev` no Debian/Ubuntu).

## Controle negativo

Em cópia descartável, remova `-static` do alvo `static` e execute `make clean test`. O teste deve falhar ao detectar `INTERP` ou `NEEDED`. Reverta e comprove retorno ao verde.
