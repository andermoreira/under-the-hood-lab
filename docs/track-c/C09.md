# C09 — Depuração real com GDB e SIGABRT

O executável em C tem um caminho normal e uma falha deliberada via `abort()`. O objetivo é obter backtrace real, identificar o frame e distinguir sinal de código de retorno.

## Previsão

Antes de executar, registre o sinal esperado, a origem da falha e o que o backtrace mostrará.

## Experimento

```sh
make -C labs/low-level/C09 test
make -C labs/low-level/C09 inspect
```

O teste funcional confirma SIGABRT real, mensagem no stderr e saída normal. `inspect` usa GDB em batch para produzir backtrace. Instale `gdb` no Linux; a execução de GDB pode depender de permissões de ptrace do ambiente.

## Controle negativo

Substitua `abort()` por `return 0` numa branch descartável. O teste deve falhar porque não observa SIGABRT. Reverta e execute novamente.

## Limites

Este laboratório não prova tratamento de falhas do kernel B12; `abort()` é um caminho de libc e SIGABRT no Linux. Registre versões, commit e saída real. ENG e LEARN permanecem NOT_RUN até evidência.
