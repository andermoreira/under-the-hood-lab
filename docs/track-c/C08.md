# C08 — Buffers e custo das syscalls no Linux real

Este experimento executa `write(2)` de verdade, não simula a syscall. Compare múltiplas escritas pequenas com menos escritas grandes para o mesmo volume total.

## Previsão

Registre antes: qual cenário tende a ter menor tempo total? Quais fatores podem confundir (cache, escalonamento, redirecionamento, CPU, clock)?

## Executar

```sh
make -C labs/low-level/C08 test
labs/low-level/C08/benchmark 10000 1 >/dev/null
labs/low-level/C08/benchmark 10 1000 >/dev/null
```

O programa imprime o tempo em nanossegundos no stderr e bytes nulos no stdout. O volume dos dois exemplos é igual (10.000 bytes). Repita várias vezes e reporte mediana, dispersão, CPU e ambiente. O relógio inclui o custo do loop e o destino `/dev/null`; não isola o custo puro de uma syscall.

## Controle negativo

Execute com zero iterações, chunk zero e argumento inválido: todos devem falhar. O teste automatizado também verifica o volume exato de saída.

## Ponte com a Trilha B

B08 tem implementação própria de syscalls; as chamadas e o ABI Linux usados aqui não demonstram compatibilidade do kernel educacional.
