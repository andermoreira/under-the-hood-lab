## Gates de conteúdo por capítulo

- [ ] Explicação que não exige termo não definido anteriormente.
- [ ] Analogia cotidiana **com limite explícito**.
- [ ] Exemplo resolvido linha a linha, com estado intermediário.
- [ ] Exercício guiado, exercício parcialmente guiado e desafio sem dicas.
- [ ] Teste negativo que identifica erro específico.
- [ ] Respostas comentadas e dicas progressivas separadas da tentativa.
- [ ] Evidência de execução (ENG/SCI) com commit e ambiente.
- [ ] Rubrica LEARN aplicada a pelo menos um estudante voluntário.

Nenhum desses itens é considerado automaticamente aprovado pela presença dos roteiros. Não marcar LEARN PASS com base em CI.
