# Checklist de revisão pedagógica

- [ ] A aula começa com uma pergunta concreta?
- [ ] A analogia está correta e limitada?
- [ ] Existe previsão antes de executar?
- [ ] Há teste positivo, negativo e limite?
- [ ] O estudante explica sem analogia?
- [ ] Existe pergunta de transferência?
- [ ] Revisão espaçada planejada?
